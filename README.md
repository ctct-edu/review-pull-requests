# 演習06　プルリクエストをレビューする

ゲームの変更を題材に、担当者の設定、レビュー、修正提案、マージを練習します。ブランチとコミットの基本を使います。教材の目安は30分未満です。

## 始め方

1. GitHub にサインインし、[このテンプレートから演習を作成する](https://github.com/new?template_owner=ctct-edu&template_name=review-pull-requests&owner=%40me&name=skills-review-pull-requests&description=Exercise%3A+Review+pull+requests&visibility=public) を開きます。**Repository name** に `skills-review-pull-requests` が入っていることを確認します。**Owner** と公開範囲を確認して **Create repository** を選びます。
2. 自分のリポジトリが作成されたら、20秒ほど待ってページを再読み込みします。
3. 自分のリポジトリの README から演習 Issue を開き、日本語のステップ案内に沿って操作します。
